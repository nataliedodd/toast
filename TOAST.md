# 🔥 Toast

**Version:** 1.0.0

## Purpose

Toast is my portable context layer.

It exists to reduce the mental load of remembering, finding,
reconstructing and repeatedly explaining the context of my life
and work.

Toast should help reduce cognitive load and protect against burnout,
not create another system that requires constant maintenance.

## Principles

### 🧠 Reduce cognitive load

If I repeatedly have to remember it, find it, explain it, measure it
or reconstruct it, Toast may be a useful place for it.

### 🎒 Portable by design

My useful context should not be trapped inside one AI tool,
application or employer.

Toast should use open, portable formats wherever practical.

### 👤 Career-portable

My professional knowledge, methods, learning and reusable tools
should remain separate from employer-specific information.

Changing jobs should not mean rebuilding my professional toolkit.

### 🔐 Boundaries matter

Personal, Professional and Employer context are separate domains.

Access to one should never automatically imply access to another.

### 🪶 Lightweight

Toast should reduce admin, not generate it.

We will not add databases, metadata, integrations or complex
infrastructure until they solve a real problem.

### 📚 Source-aware

Toast should distinguish between:

- Things I have explicitly recorded
- Measurements and known facts
- Estimates
- Information retrieved from other sources
- AI-generated or inferred information

### 🤖 AI-independent

Toast is not the memory system of any individual AI.

AI tools are consumers of Toast context. Toast remains the source
of truth.

### 🔧 Learn by building

Toast is also a practical learning project for understanding MCP,
AI context architecture and modern software development.

## Context Domains

### 🏠 Personal

Context about my personal life, home and projects.

### 🎓 Professional

Career-portable knowledge, learning, methods and tools that remain
useful independently of a particular employer.

### 🔒 Employer

Employer-specific context.

Employer context must remain isolated and should only be stored
where doing so is permitted.

## Decision Test

Before adding something to Toast, ask:

1. Will having this reduce future cognitive effort?
2. Am I likely to need this context again?
3. Is it Personal, Professional or Employer context?
4. Am I allowed to store it?
5. Does it need to be accessible to every AI connected to Toast?

If Toast creates more work than it saves, reconsider it.
